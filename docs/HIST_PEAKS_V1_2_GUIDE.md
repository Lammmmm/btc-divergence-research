# Hist Peaks v1.2：直接读出顶背离与底背离

v1.1在紧凑副图里，单根彩色柱和圆点太小，A/B编号又缺乏直观含义。v1.2将实际收盘确认提示作为视觉主体。

- 顶部红色“顶背离”，底部蓝色“底背离”：横向位置就是实际确认根；只在收盘确认后显示。提示位置在副图上下沿，不代表Hist数值。
- 实际触发根的Hist柱加粗至6像素，并在原值端点显示同色圆点。Hist高低没有放大或替换；即使Hist接近零，也能通过文字提示识别方向。
- 同向文字提示默认至少间隔20根，避免缩放后相邻文字框重叠；这是文字显示合并，每次确认柱、圆点、数据窗口及警报不变。可在设置中改成1以显示每次文字。
- 普通Hist柱继续使用灰绿（零轴上）/灰金（零轴下），默认透明度55，突出红蓝信号。
- A/B默认只保留最近1组，显示“A参照”“B末端”，配对编号默认关闭。A是历史价格枢轴及同根Hist，B是原算法比较末端及同根Hist。详细数值和时间仍在悬停提示及面板。
- 面板第一行明确写出最近“底背离 已确认”或“顶背离 已确认”，Hist及收盘价分别列出参照→末端。

A/B是在实际确认后回标的历史点，不能当作在A/B当时已经知道信号。顶部/底部文字徽标、加粗柱和圆点标明真正确认时刻。配对确认与反转成功仍是不同概念；本版不新增持续有效、取消或反转结果判断。顶部/底部文字徽标可以在设置中关闭。

没有加入竖线、连线或整段背景；不改MACD、原始背离搜索、收盘确认、同参照去重、数据窗口及警报。默认同方向同参照只显示首次；显示全部原始配对可关闭该开关。旧v1、v1.1源码和发布保留。

源码等价检查：`python src/verify_hist_peaks_v12.py`。结果与TradingView实图记录保存在 `results/hist_peaks_v1_2/`。本次为显示优化，没有重新估计收益或胜率。
