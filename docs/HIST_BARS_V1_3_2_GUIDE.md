# Hist Bars v1.3.2：右侧状态框

在v1.3.1柱图右上角恢复小型状态框，默认开启。柱色、MACD、原始背离搜索、结构跟踪和警报均不改动。旧版保留。

状态框只占六行：

| 行 | 内容 |
| --- | --- |
| 当前状态 | 底/顶背离生效中，或已确认/已失效后等待新背离。盘中触及失效位时改为“触失效位，待收盘”。 |
| 触发价格 | 本轮正式背离的末端收盘价，与原算法选中的历史价格枢轴收盘价比较。 |
| 触发Hist | 上述两根K线的原始Hist比较；底背离为末端更高，顶背离为末端更低。 |
| 反转确认价（冻结） | 底背离：收盘严格高于冻结区间最高价；顶背离：收盘严格低于冻结区间最低价。 |
| 背离失效价（冻结） | 底背离：收盘严格低于冻结区间最低价减ATR缓冲；顶背离：收盘严格高于冻结区间最高价加ATR缓冲。 |
| 正式触发 | 收盘确认、原脚本拐头条件和连线检查全部通过。 |

触发依据在正式事件开始时冻结：历史参照使用原算法返回的`span`，末端使用`[1]`。面板展示的是“本轮为何触发”，不会把最新Hist值伪装成当时的触发值，也不会被本轮期间忽略的其他原始信号覆盖。

没有进行中的背离时，中间两行显示底背离/顶背离的价格与Hist关系；两条结构价位显示横杠，避免误用上一轮边界。不能只给一个“触发价”来承诺背离：价格和Hist关系、拐头、连线检查、收盘确认需要共同成立。

盘中触线只更新状态框文字，不改变红/蓝柱，也不提前正式结束事件。等于冻结价位不算收盘严格越界，沿用原规则。反转确认结束与结构失效是两种不同结束原因。红/蓝柱仍持续到事件结束，之后恢复普通正负柱色。

面板通过设置 → 输入 → 显示 →“显示右侧状态框”关闭。无label、圆点、A/B、连接线、白色或橙色状态柱。`results/hist_bars_v1_3_2/checks.json`记录与v1.3.1的源码等价检查；这是显示更新，不重复收益回测。
