# Hist Bars v1.3：只用柱色看开始和结束

本版保留原始 MACD Histogram，去掉所有 label、A/B、文字徽标、圆点、竖线和连线。默认关闭面板，只画Hist柱及零轴。

| 柱色 | 含义 |
|---|---|
| 灰绿/灰金 | 普通正/负Hist，没有进行中的正式背离 |
| 蓝色 | 底背离正式生效；第一根蓝柱是开始，蓝柱持续到原规则结束 |
| 红色 | 顶背离正式生效；第一根红柱是开始，红柱持续到原规则结束 |
| 橙色（收盘） | 本根按原冻结边界确认失效，事件结束 |
| 浅灰色（收盘） | 本根完成原冻结结构的反转确认，事件结束 |

结束后恢复普通正负柱颜色。Hist的高度和正负始终是真实原始数值，柱色表示价格结构事件，不由Hist跨零轴决定。

## 开始、失效沿用哪套规则

v1.2仅展示每次原始背离配对，没有持续生效或失效状态。为了表达开始到结束，本版重新使用已经研究的 Hist Line v4.6.1 正式事件跟踪，删除其中可选标签后，MACD、价格枢轴、连线检查、拐头、收盘确认及冻结结构生命周期源码块逐字一致。

- 默认 MACD 12/26/9；Close枢轴左右5根；检查10个枢轴；最大跨度100根。
- 开始时冻结整个比较区间的最高/最低价及ATR(14)。底背离确认位=区间最高价，失效位=区间最低价−0.5ATR；顶背离反之。
- 后续收盘严格越过确认位，记为反转确认；严格越过失效位，记为失效。等于边界不结束。边界不随以后行情移动，没有强制等待根数。
- 同一事件进行中，后续原始信号不改方向、不重置边界。所有原始信号长度仍保留在数据窗口。**因此本版接受的开始次数不等于v1.2的原始配对数量。**

盘中触及已有失效边界时，当前柱临时变为半透明橙色预警；若收盘未越界，恢复红/蓝；只有收盘正式失效才保留橙色历史柱。触线与失效的原始价位检测来自旧规则。

若同根收盘结束旧事件并开始新事件，整柱显示新事件红/蓝，靠零轴四分之一保留旧事件结果的橙/浅灰。这只在少数同根切换时出现，Hist整柱高度不变。数据窗口同时保留旧结果和新开始。

设置中的“显示当前状态和冻结价位”默认关闭，需要时可开启3行小面板。数据窗口始终可查看开始、结束、当前方向、确认价和失效价。没有创建任何TradingView警报；脚本提供原生命周期4种警报条件供手动选择。

## 验证

`python src/verify_hist_bars_v13.py`：原MACD及生命周期源码等价；不存在label/shape/circle调用。4H的12,684根、1D的2,114根研究区间回放与旧生命周期逐根一致，开始分别202/39次，失效118/11次，反转确认83/27次，各留1个未结束事件。7项边界断言覆盖未收盘、边界等值、同根结束并开始及期间反向信号不重置。

这是显示与既有生命周期对账，不是新收益回测；Python回放不是Pine解释器。TradingView运行、无标签视觉检查及源码回读记录单独保存在 `results/hist_bars_v1_3/tradingview_checks.json`。旧v1、v1.1、v1.2、Line v4.6.1均保留。
