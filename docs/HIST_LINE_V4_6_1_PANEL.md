# Hist Line v4.6.1：面板信息顺序修正

本版只调整面板顺序，曲线与 v4.6 完全相同。它不是缩短横线的新算法。v4.5.2 固定基线和 v4.6 均保留。

## 为什么之前看起来相同

v4.6 保留了同一条主线、同一事件和冻结边界，只增加“期间信号（不切换）”一行。它在旧面板最后一行，较矮副图会将这一行裁掉。因此主线相同是设计结果，而新增信息在截图中也不可见。

## 本版顺序

1. 当前事件状态。
2. 期间信号（不切换）：同向新参照或曾出现的反向背离，按历史枢轴去重，反向信息优先。
3. 冻结反转确认价和收盘越界方向。
4. 冻结背离失效价和收盘越界方向。
5. 当前曲线数值。
6. 非概率及结构位置说明。

期间信号表示历史发生记录，不表示它现在仍然有效，也不会重置当前事件、自动切换方向或缩短横线。面板仍为六行；极矮副图需要适当拉高才能全部显示。颜色保持正式顶背离 100 横线红色、底背离 0 横线蓝色，其余连接灰色。

## 同步完成的研究

[失效边界对照报告](../reports/HIST_BOUNDARY_COMPARISON.md)比较原边界、末端6根、末端2根，保持 MACD、正式原始信号和反转确认价一致。两个候选方案未达到预先记录的替换条件，未部署到 Pine。

4H 横线占用仅减少约1.2%–1.3%；日线最激进方案减少10.3%，但同起点对照提前判失效2个原本成功事件。结构确认率不是收益率。本轮没有新增交易收益回测，也不是新的样本外验证。
