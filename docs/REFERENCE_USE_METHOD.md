# 这一轮只研究日常参考用途

问题：在 BTCUSDT 永续的日线和4H上，应该开启哪些聚合背离项目、是否要求两项共振、是否必须等待日线同向、是否需要趋势/震荡过滤？

候选来自上一轮，日线限定 Hist/RSI/MOM，4H限定 Hist/OBV。最初固定12种设置；看到RSI表现较弱后，只追加1种明确标记为探索性的日线Hist或MOM设置。没有扩展到其他指标组合，也没有搜索拐点周期、ADX阈值、日线背景有效期或观察期限。方案与追加理由均单独保存。

## 观察口径

日线观察信号确认后10天，4H观察后3天。为了评价提示是否及时，以“先顺向达到1个信号时ATR，还是先逆向达到1ATR”为主要结果；到期涨跌方向、顺向及逆向最大波动为次要结果。交易费用、资金费、止损仓位不纳入本轮，因为这次评估的是参考提示，不是交易策略。

1H内同时碰到两边按逆向先到；未触及两侧仍计入分母。每个设置完整观察期内不再采用新的同向或反向提示，即使1ATR边界已提前触及。因此表中年频率是去重事件频率，屏幕实际标签会更多。全期、前段、近期分别重放并清除边界事件，不能强求前段+近期等于全期。

## 多周期信息

4H信号只可使用当时已收盘的日线。日线背景为最近合格的方向事件，最多保留10天；同等级反向事件替换，同日双向冲突清空。至少1项和至少2项的日线背景分别维护。比如至少2项背景不会被仅1项反向信号自动取消。这是固定实验定义，尚未验证不同有效期更好。

所有4H日线过滤实验仍基于Hist/RSI/MOM三项日线候选池；不能把其57.14%的统计搬到最终只开MOM的设置上。

行情分类使用已收盘日线Wilder ADX14：<20震荡、>=25趋势、20–25过渡；方向由+DI/−DI决定。只作分组诊断，不在看到结果后添加行情过滤策略。

## 如何解读选择

MOM的日线单项和Hist的4H单项是这轮简化观察的暂用选择。日线MOM全期只有35次，优势主要来自顶背离；并未证明是普遍最佳或可直接交易。4H Hist先顺向1ATR仅约49%，到期方向正确约61%，不能把后者理解为及时反转成功率。

三项日线任意1项、Hist+MOM任意1项都未改善日线MOM单项的主要结果。4H至少两项共振变差。日线至少两项同向的4H过滤在全期只有35次、近期12次，且保留约11%的提示；可以作为未来稀疏关注的研究线索，不能作为当前已验证的硬过滤。

相同事件池拆分“恰好1项/多项”“日线同向/反向/无背景”只用于诊断，不能与另行重放过滤设置的统计混用。

本轮沿用已检查的历史数据与价格异常处理。所有数据已经被查看，无真正未见样本；Wilson区间为描述性，未校正选择、多重比较及序列相关性。TradingView逐根对账仍待完成。
