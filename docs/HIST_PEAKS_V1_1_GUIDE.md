# Hist Peaks v1.1：双色普通柱与突出确认点

2026-10-21，基于 v1 的纯显示更新，v1 源码与发布保留。

- 零轴上方普通 Hist 柱：灰绿色 #668E7B；下方：灰金色 #A88B60，默认透明度40。颜色只表示 Hist 正负，不表示背离。
- 正式展示确认：底背离亮蓝 #2979FF、顶背离亮红 #FF1744，覆盖普通柱色，完全不透明。
- 在真正确认根的原始 Hist 值处增加同色圆点，解决 Hist 接近零时彩色柱太短的问题。圆点不回标、不改变 Hist 值。
- 默认只保留最近2组 A/B 小标签，取消标签内数值；悬停仍有完整 Hist、Close、历史位置及真正确认时间。面板仍显示最近一组 Hist/价格。
- “保留最近配对组数”设为0可关闭所有 A/B 标签；信号柱、确认点、数据窗口和警报不受影响。也可重新开启标签内数值。
- 默认关闭上下沿确认三角；真正确认位置由彩色柱与圆点表达。
- 面板从6行减为5行，保留最近配对、Hist、Close、确认时间和回标说明。

MACD、价格枢轴、正式背离搜索、收盘门槛、同参照去重、A/B数值、数据窗口及警报代码与v1逐字一致。默认同参照只标首次的口径也不变，后续同参照原始信号不额外染色；需要显示全部原始配对，可关闭该开关。没有加入新的背离判断或成功/失效规则。

A/B是在收盘确认后回标的历史比较点，不能用它们的历史位置当作当时已知信号。具体算法与复盘边界见 [v1说明](HIST_PEAKS_V1_GUIDE.md)。

源码等价检查：`results/hist_peaks_v1_1/checks.json`。TradingView实图检查单独记录；不把视觉调整当作新收益回测。
