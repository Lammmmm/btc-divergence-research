# 连续单折线 v4.1

完整使用说明、计算例子、参数表和复盘步骤见 [指标完整手册](HIST_INDICATOR_MANUAL.md)。

本版只改显示。正式背离、冻结结构、确认/失效、候选枢轴计算与 v4 完全一致。

- 副图只有一条连续细折线，默认线宽 1。移除全部三角、圆点、叉号和重置菱形；详细文字标签默认关闭。面板缩为两行。
- 底背离橙色，顶背离蓝色；形成阶段颜色较淡，正式生效后实色。条件破坏或触失效位立即红色；反转收盘确认绿色。
- 形成阶段只展示一个重点方向。首次选两项综合程度较高者；之后保持方向，只有当前分数低于 50 且另一方向高出 25 分，或当前方向失去候选，才切换。另一方向仍完整计算，可在数据窗口检查。
- 默认对形成分数做 3 根 EMA 式显示平滑（系数 0.5），同一参照内递推；改变参照或阶段时重置，不混合不同枢轴的分数。设置为 1 可显示未经平滑的形成分数。平滑有滞后，原始分数及红色警示不延迟。
- 正式触发根直接显示新冻结结构的实际位置，取消人为跳到 100 又落回结构值的尖峰。形成全部完成的 100 保留在数据窗口“正式形成确认 100”，正式生效由实色、面板和原有警报表达。
- 结构阶段完全不平滑：当前位置仍严格按 `(价格-失效价)/(确认价-失效价)*100` 计算并限制在 0–100。失效=0、反转确认=100。
- 换参照、方向或阶段的连接段使用灰色，表示更换计算口径，并非同一次背离继续发展。红色危险警告、绿色结果优先于灰色；每次切换都保留在数据窗口“主线参照或阶段切换”。
- 没有可用候选时保持上一个数值，以灰线连接，面板明确显示“暂无候选”；该灰线位置不代表进度。最早无候选时以 50 为中性连接值。

为了连续展示，本版会连接不同口径的点，必须结合颜色及数据窗口辨认切换。没有用未来数据补线，也没有把平滑值用来触发交易信号。百分比不是成功概率。历史仍是收盘快照，不能恢复历史 OHLC 未记录的盘中瞬时变化。

使用 `pine/Hist_Divergence_Line_v4_1.pine` 替换 v4。运行 `python src/verify_hist_line_v41.py` 检查正式/候选计算源码一致、单曲线零图形标记、14,798 根历史显示值连续且有界、结构值未平滑及前缀稳定性。TradingView 编译/实图检查另存；不将离线规格测试冒充完整 Pine 历史对账。
