# Hist 背离状态 0–100 v3

按用户要求重做坐标系统：**底背离正式生效时为 0（黄色），顶背离正式生效时为 100（蓝色）。** 本版是状态坐标，采用原有 Hist 背离信号，不是 RSI，也不是反转概率。

| 状态 | 坐标 | 颜色 |
|---|---:|---|
| 普通观察 | 10–90 | 灰色 |
| 潜在底背离，尚未收盘生效 | 5 | 灰色 |
| 潜在顶背离，尚未收盘生效 | 95 | 灰色 |
| 底背离生效、等待结果 | 0 | 黄色 |
| 顶背离生效、等待结果 | 100 | 蓝色 |
| 反转确认或结构失效 | 回到观察或潜在状态 | 灰色 |

生效期间折线停留在 0 或 100，形成水平段，用长度显示已等待多久。事件在收盘结束才离开边界。若同一根收盘结束旧事件又启动新事件，直接转到新事件的边界。历史生效段保留颜色，不会在事件结束后被擦除。连接相邻柱的斜线只是绘图插值，信号时刻以柱的状态值为准。

普通观察段使用当前及过去 100 根 Hist 的最小/最大值，映射至 10–90：`10 + 80 × (Hist - 最小值) / (最大值 - 最小值)`；区间无波动或没有有效值时使用 50。这个窗口只影响显示，不参与背离判定。5/95 是潜在形态的固定状态标记，不表示有 95% 的概率变为正式背离；潜在形态可以撤销，观察段也可以跳动。

## 确认与失效

检测、冻结确认位/失效位、等待不限根数、收盘判断及警报规则全部沿用 v2。未收盘时即便价格越界，正式状态仍等待收盘；有生效事件时，新的背离提示不重置冻结边界。详见 [原始生命周期说明](HIST_LIFECYCLE_GUIDE.md)。面板仍显示从提示价到确认/失效边界的价格距离进度，该百分比与 0–100 状态坐标是两件事，均不是胜率。

## 显示与安装

把 `pine/Hist_Divergence_State_v3.pine` 的完整内容放入 Pine 编辑器，保存并更新图表。原始 MACD、Signal 和 Hist 不再绘制到副图坐标上，原始 Hist 仅在数据窗口中查看。保留 0、50、100 三条水平参考线，无竖向色带或背离连接线。可选事件标签也使用 0/50/100 坐标，避免打开标签后纵轴被价格拉伸。

默认事件标签关闭、进度面板开启。底部黄色、顶部蓝色及观察灰色都可调整。研究默认仍为 BINANCE:BTCUSDT.P 日线和 4H，MACD 12/26/9，枢轴 5，检查枢轴 10，最大跨度 100，失效缓冲 0.5 ATR(14)。恢复默认输入可清除旧显示设置。TradingView 可能在 0 和 100 之外留轴边距；所有实际折线数值严格在 0–100。若沿用旧手动纵轴，应把本副图纵轴恢复“自动”。

## 验证与复现

运行 `python run_hist_state_v3.py`，结果与日志保存在 `results/hist_state_v3/` 和 `logs/hist_state_v3_*`。

- 8 项新测试：恒定/缺失值、普通极值不能伪装成背离、潜在状态、正式状态优先级、随机范围、前缀因果性、盘中/结束转换、失效与同根新事件。
- 8 项既有生命周期回归测试。
- 对保存的 2,114 根日线和 12,684 根 4H 状态逐根验证：生效底背离恰为 0、生效顶背离恰为 100、其他状态不能达到边界、结束且无新事件后回灰。
- 核对 Pine 核心代码与 v2 一致（仅事件标签 Y 坐标变化）；警报一致；副图唯一可见数值曲线是状态坐标。

这些离线测试是 Python 规格验证及源码对照，不能冒充 Pine 执行。TradingView 编译、保存源码比对及两个周期实图检查另见 `results/hist_state_v3/tradingview_checks.json`。完整历史 TradingView 导出对账尚未完成。本次不新增或改写交易收益/反转准确率结果。
