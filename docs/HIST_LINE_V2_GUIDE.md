# Hist 背离折线 v2

将 MACD Histogram 数值画成连续折线，沿用 v1 的背离检测和结构跟踪。它不是 RSI，数值不限制在 0–100。

## 颜色与阶段

| 阶段 | 折线 | 面板 |
|---|---|---|
| 观察或潜在形态 | 灰色 | 观察中 / 潜在底背离 / 潜在顶背离 |
| 收盘确认底背离，结构尚未结束 | 黄色 | 底背离生效 · 等待反转 |
| 收盘确认顶背离，结构尚未结束 | 蓝色 | 顶背离生效 · 等待反转 |
| 反转确认或结构失效 | 恢复灰色 | 最近完成事件及结果 |

颜色持续覆盖该事件的生效区间；不会只给触发当根着色。已经结束的历史区间保留当时的颜色，便于复盘。若旧事件结束的同一根又确认新事件，直接使用新事件颜色。潜在形态仍可能撤销，只有正式生效后折线才变色。盘中越界仍等收盘才结束事件。

移除了柱状图、状态带及散点标记；不绘制竖向背景条或背离连接线。保留水平零轴。默认只显示一条宽度为 3 的 Hist 折线和进度面板；事件标签、额外 MACD/Signal 两条线均默认关闭。颜色、线宽可在设置中修改。面板的价格位置进度可前进或回退，**不是反转概率或胜率**。

## 安装

在 TradingView 的 Pine 编辑器中用 `pine/Hist_Divergence_Line_v2.pine` 全部内容替换本指标旧版，保存并更新图表。若从旧版更新后保留了旧输入设置，请关闭“显示生效 / 结果标签”和“同时显示 MACD / Signal 线”，或恢复本指标默认输入。其他独立指标自己绘制的竖线不受此脚本控制。

研究对应图表为 BINANCE:BTCUSDT.P，日线或 4H。默认参数仍为 MACD 12/26/9、枢轴 5、检查枢轴 10、最大跨度 100、结构失效缓冲 0.5 ATR(14)。未新增参数搜索或修改此前回测数据。

原有算法、确认/失效定义和研究限制详见 [v1 使用说明](HIST_LIFECYCLE_GUIDE.md)。本版静态校验记录在 `results/hist_lifecycle/line_v2_checks.json`，图表截图位于 `reports/hist_line_v2_*_tradingview.png`。编译/显示验证不等于完整历史信号对账。

绘图实现参考 [TradingView 官方 plot 文档](https://www.tradingview.com/pine-script-docs/visuals/plots/)：使用 `plot.style_line` 和逐根状态颜色，不改变 Hist 序列。
