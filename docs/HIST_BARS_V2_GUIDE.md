# Hist Bars v2.0：回到原版确认条件

v1.3.2已先归档到GitHub `hist-bars-v1-3-2`，提交`35ecc43`，含源码、说明、截图和完整历史数据包；该版本保持原样。

v2.0是独立的Hist普通背离信号柱。枢轴数组维护、两段背离搜索函数直接复制自最初的`original_user_source.pine`，保持Pine v4以避免语言迁移引入判断变化。只选择MACD Histogram的普通背离分支，等价于原聚合脚本仅勾选Hist、Regular、最少背离数1。未恢复其他振荡指标或隐藏背离。

## 保留与取消

保留原版MACD 12/26/9、价格枢轴、最近枢轴数、最大跨度、Hist与价格的对应关系、连线检查和原版`Don't Wait for Confirmation`选项，默认不勾选。默认参数仍为Close、枢轴5、检查10个枢轴、最大100根跨度。

删除后来添加的反转确认价、背离失效价、ATR缓冲、起始日期过滤、额外收盘锁定、active事件延续、冷却/去重以及“未结束时忽略新背离”。不再输出结构成功/失败警报。

## 柱色怎么读

| 当前原版检测结果 | 柱色 |
| --- | --- |
| 本根检出普通底背离 | 蓝色 |
| 本根检出普通顶背离 | 红色 |
| 本根未检出 | 恢复原有普通正负柱色 |
| 同根两侧都检出 | 两信号和警报都保留，柱色顶红优先；框内注明双向同时触发 |

每一次执行都重新判断，没有跨根锁定。连续多根条件成立就连续变色；下一根不成立就恢复普通色。变色标在**实际检测到信号的当前K线**，不回填到上一根或历史枢轴。Hist数值本身未改动，无label、圆点、A/B或连接线。

普通柱只表示“本根未检出”，不表示上一轮已达到某个结构失效价。本版已经移除了那套结构结果定义。

## 原版的“确认”含义

默认`Don't Wait for Confirmation=false`时，原版以**上一根**为背离比较末端，并要求本根Hist或收盘价发生相应方向拐头，再通过连线检查。底背离的拐头是Hist上升或close上升，顶背离相反。它**不等于强制等待当前K线收盘**。

因此，和原版一样，实时未收盘K线可能先显示红/蓝，随后条件不再满足而恢复普通色。历史只保留K线最终执行结果，无法从历史OHLC重建盘中每个tick的闪现。若创建警报并希望只收最终结果，可在TradingView警报频率中选择“每根K线收盘一次”；这属于警报设置，不额外改变脚本的原版检测。

勾选`Don't Wait for Confirmation`后，原版改用当前K线为末端并跳过拐头门槛，连线检查仍保留。

## 右侧状态框

保留简洁的当前检测、价格条件、Hist条件、原版确认方式及实时说明。无冻结确认价和失效价。状态框显示的是当前K线的检测结果，不延续上一轮事件；可以在输入设置关闭。

## 验证范围

`src/verify_hist_bars_v2.py`核对原版源码块、MACD声明、独立警报和显示映射，并将默认Close/等待确认模式下4H、1D的全部历史Hist信号长度与既有原版研究记录逐根对比，保存`results/hist_bars_v2/`。这不是盈利回测，也不是Python执行Pine。High/Low和不等待确认模式保留原版源逻辑，但不能用默认模式的历史对照冒充覆盖这些选项。TradingView实际编译与截图另行记录；如未全量导出逐根核对，会明确标注。
