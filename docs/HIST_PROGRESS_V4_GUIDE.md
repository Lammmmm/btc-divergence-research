# Hist 枢轴形成与结构进度 v4

本版替换 v3 的固定状态数值。形成阶段：底背离橙色细线、顶背离蓝色细线，分别在 0–99 变化。正式触发用 100 处的同色三角形表示；随后只显示该事件的结构位置曲线，失效边界为 0，反转确认边界为 100。红色表示条件撤销/连线阻断或结构触线预警，绿色圆点表示反转收盘确认，红色叉号表示结构收盘失效。所有百分比均非概率。

## 形成进度的确切基准

1. 完全沿用原算法基于 **Close** 的已确认高/低枢轴数组，默认左右各 5 根确认。枢轴只在右侧确认根收盘后加入数组，图形不回填到该枢轴发生时。
2. 每个方向独立选择原算法最近 10 个枢轴池中，当前跨度大于 5 且不超过 100 根的**最近一个**。不按进度高低挑选，不用 Hist 零轴、超买超卖或历史极值代替枢轴。没有合格参照时该方向曲线留空。
3. 取枢轴 K 线的 Close 为 `P0`，同一根 K 线的 Hist 为 `H0`。当前尚未确认的形成端点用当前价格 `P` 和当前 Hist `H`。
4. 新参照选定时，冻结前一根已收盘 ATR(14) 为 `A`、前 20 根已收盘 Hist 的总体标准差为 `S`。分母至少取一个最小报价单位，避免无波动时除零。冻结仅适用于这一参照的形成显示，避免波动率分母变化制造进度变化。换参照后重新冻结。进度范围参数默认各 1，可改显示敏感度，不能改变正式信号。

| 项目 | 底背离 | 顶背离 |
|---|---|---|
| 价格有利距离 `dp` | `(P0 - P) / A` | `(P - P0) / A` |
| Hist 有利距离 `dh` | `(H - H0) / S` | `(H0 - H) / S` |

`价格接近程度 = clamp(100 × (1 + dp / 价格范围), 0, 100)`

`Hist接近程度 = clamp(100 × (1 + dh / Hist范围), 0, 100)`

`形成综合进度 = min(99, 价格接近程度, Hist接近程度)`

例如两项为 100 与 20，综合只有 20，不能因为一项达到条件就显示接近完成。等于枢轴值时组件可为 100，但原算法要求严格不等式，**综合仍最多 99，绝不会因此生成正式信号**。形成程度可增加、降低或归零；不是不可逆的完成百分比。

## 正式确认不改原规则

正式信号仍由原 `f_find(hist, ..., start=1, requireTurn=true)` 产生：比较前一根端点和原始枢轴，逐根检查价格与 Hist 的虚拟连线，再通过当前根 Hist 或 Close 拐头条件，最终等当前根收盘。候选形成显示使用 `start=0` 的当前端点，与正式确认端点相差一根，不能把形成线当成正式信号。

原算法会按顺序查找最近 10 个枢轴中的**第一个全部条件通过者**，它可能不是当前显示的最近候选枢轴。正式触发时必须以原算法实际选中的枢轴为准，不受显示候选的选择限制。100 处的正式三角独立绘制，不把候选曲线强行连到一个不同参照的正式点；数据窗口保存实际正式枢轴时间、Close、Hist，可逐项复核。

形成曲线在以下情况断开：参照切换、参照到期、正式触发、事件结束后重启观察。换参照使用同色小菱形标记，参照到期用灰色叉号。参照的条件记忆和归一化分母同时重置。这里选择明确断线，而不是把不同参照点拼成一条看似平滑的形成路径。

## 形成条件撤销与实时提示

对当前候选也执行原脚本的价格/Hist虚拟连线检查（当前端点）。曲线变红表示当前连线被中间 K 线阻断，或此前在该参照下已收盘满足的价格/Hist严格关系现已不满足。条件恢复后可恢复橙/蓝。红线的数值仍是两项端点接近程度，可能为 99，但连线阻断意味着它不能正式确认。面板明确提示“关系撤销或连线阻断”。

盘中使用最新 Close/Hist 更新形成曲线，不需要等收盘；已收盘的“曾满足条件”记忆只在收盘提交。未收盘瞬时变化允许撤销，不使用 `varip` 把无法在历史 OHLC 中还原的路径伪装成历史事实。

## 生效后的结构进度

生效时仍按旧版冻结原区间最高/最低价和 ATR，确认价 `C`、失效价 `I` 与原研究一致：底背离以原区间高点为确认价，区间低点减 0.5 ATR 为失效价；顶背离相反。

`结构位置 = clamp(100 × (当前价格 - I) / (C - I), 0, 100)`

同一个公式同时适用于多空，失效价必为 0，确认价必为 100。**这与旧版从提示价出发的正负距离进度不同**；新版完整表达失效价至确认价之间的位置。

- 正式触发根：100 处三角形表示形成条件全部通过。面板立即显示新冻结结构的实际位置；结构曲线从下一根开始，明确切换口径，不把“形成 100”接成“结构 100”。
- 结构存续期间：只有一条对应方向曲线，宽度默认 2；价格向失效边界靠近时数值下降，向确认边界靠近时上升。
- 底背离当根 `low <= I`、顶背离当根 `high >= I` 时立即红色预警并在 0 处留小红点；即便价格收回，本根触线记录仍可由 high/low 复盘。当前位置依然用最新价格计算，不把一次触线永久锁死为 0。
- 正式失败仍要求收盘**严格**越过失效价，等于边界或影线穿越不算正式失败；反转也仍需收盘严格越过确认价。盘中到 100 只代表触及确认价，绿色结果圆点才代表收盘确认。
- 不把生效前本根已经发生的影线拿来触发新事件的预警。旧事件同根结束并产生新事件时，红点属于旧事件，新事件显示自己的独立三角和结构。
- 不设置等待期限；存续期间忽略新信号，不重置冻结边界。成功或失败的结果不由后来价格改写。

## 历史可复盘的边界

历史保存当时可知的收盘形成程度、枢轴切换、正式触发、结构位置、结果和可由高低价验证的结构触线。没有未来回填、负偏移或跨周期前视。修改参数、图表加载的历史起点变化、交易所修订行情仍可能改变重新计算的输出。

**普通历史 OHLC 不能完整恢复每次实时 tick 中出现又消失的潜在形成变化，也无法确定同一根内高低价的先后顺序。** 本版不会声称能保留这些无法重建的瞬时路径。需要逐 tick 取证时应另行记录实时数据；目前的历史形成曲线是收盘快照。

## 使用与审计

加载 `pine/Hist_Divergence_Progress_v4.pine`。默认 4 行小面板、无大文字标签、无竖线或背离连接线。小标记：菱形=新参照，三角=正式背离，绿圆=反转确认，红叉=收盘失效，0 处小红点=触线预警。

数据窗口包含两方向枢轴时间、枢轴 Close/Hist、价格/Hist分项得分、冻结归一化尺度、连线检查、撤销标志、正式事件实际参照和结构价位。测试与历史逐根记录保存在 `results/hist_progress_v4/`，可运行 `python run_hist_progress_v4.py` 重现；日志在 `logs/hist_progress_v4_*`。

本轮通过 14 项形成/结构测试及 8 项既有生命周期测试。2,114 根日线、12,684 根 4H 正式信号和生命周期与保存的旧版记录一致，分别含 39、202 个事件。前缀重算验证后续数据不改写较早输出。离线工具是 Python 规格验证，并非 Pine 解释器；TradingView 编译/显示检查单列保存，完整历史导出对账仍待完成。形成进度没有经过预测准确率优化，不沿用旧回测胜率作概率解释。

参考：[TradingView 执行模型与实时回滚](https://www.tradingview.com/pine-script-docs/language/execution-model/)、[官方绘图说明](https://www.tradingview.com/pine-script-docs/visuals/plots/)。
