# Hist Peaks v1：原始 Hist 与背离比较点

独立副图，暂时放下 0–100 进度折线和长期横线。旧版 v4.6.1、v4.5.2 及其研究全部保留。

## 读图

- 灰色柱：原始 MACD Histogram（MACD 线减信号线），没有归一化或视觉平滑。
- 蓝色 A/B 标签：底背离；红色 A/B 标签：顶背离。同一编号是一组。
- A：原算法选中的历史 **Close 价格枢轴**及同根 Hist；B：正式检查使用的末端 K 线及其 Hist。
- `H` 是 Hist 数值；`P` 是对应收盘价。标签尖端落在该根实际 Hist 数值。
- 底背离要求 B 的收盘价低于 A、Hist 高于 A；顶背离反之，还必须通过原连线检查和拐头条件。
- 小三角及彩色柱标明**实际收盘确认的 K 线**。A/B 标签在该根收盘后回标到历史位置；悬停可看 A/B 时间及实际确认时间，均为 UTC。
- 右侧面板列出最近展示配对的 Hist、Close 和实际确认时间。它不是当前有效交易状态。

**这里的“峰谷”是原算法实际比较位置，不保证是 Hist 独立局部极值。** 不把 A/B 移到邻近更好看的柱顶或柱底。若正式确认发生于 t，A 在 t−span，B 在 t−1；直到 t 收盘才可以知道这组配对成立。

## 与折线版的区别

| 项目 | Hist Line v4.6.1 | Hist Peaks v1 |
|---|---|---|
| 纵轴 | 0–100 展示值 | 原始 Hist 数值 |
| 主体 | 形成曲线与触发后的横线 | Hist 柱状图与 A/B 点 |
| 原始 MACD、Close 枢轴、背离搜索 | 原规则 | 同一源码块，逐字保留 |
| 展示范围 | 单个前台事件，等待冻结边界结果 | 原始收盘配对独立展示，不等上一事件结束 |
| 反转成功/失效 | 原冻结结构结果 | 本版不新增、不替代该结果判定 |
| 同参照重复 | 由旧生命周期处理 | 默认同方向同 A 只标首次，可关闭 |

因此新图可展示旧版等待期间已经发生的原始配对，但**不能把新标签数量当作旧版接受事件数，也不能套用旧版胜率**。这是显示口径变化，底层背离条件未改。没有使用局部反转完成方案。

## 默认设置

MACD 12/26/9；Close 枢轴左右各 5 根；最多检查 10 个最近枢轴，跨度不超过 100 根。默认从 2021-01-01 UTC 起展示。

默认保留最近 6 组（12 个标签）；更早标签被成对删除只为减少遮挡，数据窗口中的历史原始信号不删除。窄副图可改为 3 组，或关闭“标签显示 Hist 和对应收盘价”，数值仍可在悬停和面板查看。

“同方向同参照只标首次”仅减少重复标签和展示三角；不会把旧 B 点移动到后来更好看的位置。关闭后展示每次原始收盘配对。原始配对警报始终不受这个显示去重开关影响，名字已与旧生命周期警报区分；没有自动创建任何警报。

## 历史与实时边界

永久标签、编号与确认标记只在收盘更新。未收盘 Hist 柱会随价格变化，但不会提前产生正式配对标签。原始比较点回标会让历史看起来提前出现信号，必须结合实际确认三角或 tooltip 时间复盘。默认只保留最近若干组标签，并不承诺保留无限历史对象。

这是原始信号观察工具，本版没有潜在形成进度、冻结结构百分比或胜率显示。

## 验证与复现

运行 `python src/verify_hist_peaks_v1.py`：

- 新旧 MACD、枢轴提交、正式搜索源码块逐字一致；
- 4H 14,880 根、1D 2,480 根离线重放，全部 Hist 背离跨度与既有研究记录一致；
- 研究区间内 4H 原始配对 341 组、默认同参照首次 237 组；1D 为 55/39 组。这些是信号数，不是交易数；
- 每组核对 A/B Hist、Close、时间方向和实际确认根；6 次前缀一致性检查、9 项边界断言通过；
- 导出全部原始配对与默认展示配对至 `results/hist_peaks_v1/`。

Python 验证不是 Pine 解释器，也不是新收益回测。TradingView 编译、实图和源码回读检查独立记录在同目录 `tradingview_checks.json`；尚未完成 TradingView 全历史导出逐根对账。
