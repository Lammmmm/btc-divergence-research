  • 原始数据：币安 USDⓈ-M BTCUSDT 永续合约成交价 OHLCV，2020-01-01 至 2026-10-15（UTC），只取完整 K 线。2020 年仅用于指标预热。

  • 保留 RSI(14)、MACD(12,26,9)、Stoch(14) 平滑3、CCI(close,10)、Momentum(10)、OBV、VWMA(12)-VWMA(26)、CMF(21)、MFI(close,14)。尤其 CCI 与 MFI 均使用原脚本指定的 close。
  • 在实际检测到信号的那根收盘后，下一根开盘入场；固定持有 5、10、20 根，最后一根收盘退出。主比较为 10 根：4H=40小时，1D=10天。不是回填到历史拐点买卖。
  • 底背离按做多收益，顶背离按做空收益；无止盈止损、无杠杆。每个指标/组合、每个方向独立计数，该方向持有期间忽略新信号，退出当根收盘的新信号可下一根开盘进入。未完成持有期的事件不计；跨越前后段边界的事件排除。
  • 手续费假设单边 0.05%，滑点单边 0.02%，按成交额计算；不是账户实际费率。另按真实历史资金费率计入支付/收取。6,342 条资金记录中 3,100 条没有标记价，用当时 4H 开盘价代理，所以资金费用属于估算。
  • 命中率=退出价相对入场原始开盘价方向正确的比例，尚未扣成本；净盈利比例与平均净收益包含手续费、滑点和资金费。持平计入分母但不算命中。
  • 多空汇总是独立事件的平均结果，不是单账户组合权益曲线。不同指标可能使用同一段行情，不能相加为独立获利次数，也不能由平均每笔收益推算年化或最大回撤。

原脚本会删换历史标签，本统计直接记录当时已经确认的条件，不按最终留下的标签挑样本；组合要求同一根、同方向达到数量。检查到本样本普通背离没有同根多空混合，数量口径与原脚本设置相符。

  • 1D 后段各单项只有 4–14 笔（10根口径）；CCI 75% 命中率只有4笔，不能据此认定它最好。4H Stoch 近期70%是50笔，全期命中率约55.9%，平均净收益仍为负。
  • 4H OBV 的全期平均净收益约+0.055%，后段约+0.074%，优势很薄；更高实际成本可以抹掉这一优势。不能把这个排名当作无需风控的开仓规则。
  • 已检查：全部 K 线连续且无重复；日线 OHLC 与6根4H聚合一致；裁掉未来数据不会改变过去指标/信号；每周期120个事件/非事件用独立逐行算法核对；验证入场时间、持有期、同方向不重叠、跨分段泄露与多空成本符号。
  • 日线成交量有两天与4H聚合不同：2023-08-16（272,023.138 对 280,542.952 BTC）、2023-11-10（299,373.892 对 287,320.597 BTC）。复查日线 API 返回一致；保留原生周期数据，未擅自修改。
  • 未与 TradingView 同时逐根导出结果进行交叉核验；这是经过内部校验的本地复现，不宣称与 TradingView 撮合器完全一致。历史价格与成交量供应差异、初始化、真实费用、资金费时间和滑点均可能影响结果。
  • 这是固定持有时间的事件回测，不包含止盈止损、杠杆、爆仓模拟，也不提供完整资金曲线。后段已被查看，后续再调参应使用新的前向样本验证。
